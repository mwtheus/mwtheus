## 🔶 Yr

`yr-lang` é uma linguagem/DSL em que o projeto inteiro mora num arquivo `.yr`: HTML, CSS, JS de frontend, JS de backend, DevOps e macros, cada um na sua seção.

Roda sozinha, pelo terminal (CLI) ou via CDN, sem depender da Yrkit. A Yrkit é a IDE oficial da linguagem.

```bash
npm i @yr-lang/yr
```
