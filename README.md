## 🔶 Yr

`yr-lang` is a language/DSL where the entire project lives in a single `.yr` file: HTML, CSS, frontend JS, backend JS, DevOps and macros, each in its own section.

It runs on its own, from the terminal (CLI) or via CDN, without depending on Yrkit. Yrkit is the official IDE for the language.

Projects and code in the [**yr-lang**](https://github.com/yr-lang) org on GitHub.

### module

```bash
npm i @yr-lang/yr
```

### cli

```bash
npm i -g @yr-lang/yr-cli
```
